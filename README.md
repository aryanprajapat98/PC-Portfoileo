# PC-Portfoileo

> **Priyanshu Choudhary — Cybersecurity Portfolio & Telemetry Hub**  
> *Offensive Security • Threat Correlation • Reverse Engineering*

An ultra-responsive, high-fidelity personal portfolio and security engineering hub built to showcase offensive security tooling, threat correlation engines, malware reverse engineering, and professional credentials with Apple Cupertino minimalist discipline.

---

## ⚡ Featured Security Suites

- **Recon Suite**: Live interactive network port scanner with real-time port state inspection (SSH 22, HTTP 80, HTTPS 443, SMBv1 445 vulnerability alert).
- **Threat Detection Engine**: Real-time packet ingestion stream with toggleable anomaly density waveform graph and filter modes.
- **Reverse Engineering Suite**: Interactive Ghidra decompiler opcode viewer with address navigation and seed entropy breakdown.
- **Honeypot Telemetry Node**: Interactive decoy node sensor map with live hit clusters, threat actor counters, and captured shell payload logs.
- **Integrated Resume System**: Cupertino-styled printable modal preview with instant one-click browser print/PDF export.

---

## 🛠️ Tech Stack

- **Core**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Vanilla CSS
- **Icons**: Lucide React & Google Material Symbols
- **Design System**: Apple Cupertino Minimalist Aesthetic

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ or v20+)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/aryanprajapat98/PC-Portfoileo.git
   cd PC-Portfoileo
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
